# Third-party data and attribution

No third-party data are redistributed in this repository, except `pipeline/data/airports.json` (see the OpenStreetMap row). `pipeline/data/adsb_manifest.json` lists only file names, URLs, sizes and checksums of ADSB.lol release files, no ADS-B data. Terms below were checked on the providers' websites on 2026-10-11.

| Source | Used for | Terms |
|---|---|---|
| PRC Data Challenge 2026 data (OpenSky Network and EUROCONTROL Performance Review Commission) | Training and test inputs | As set by the organisers. Not redistributed. |
| OpenStreetMap contributors | Airport boxes, runways and stand positions in `pipeline/data/airports.json`; part of the merged stand table | © OpenStreetMap contributors. Data available under the Open Database License (ODbL) 1.0, https://opendatacommons.org/licenses/odbl/1-0/. `airports.json` is a derived database and is made available under the ODbL 1.0 (see `pipeline/data/NOTICE`), independently of the GPL that covers the code. |
| ADSB.lol `globe_history_2025` and `globe_history_2026` releases | ADS-B ground trajectories | The repositories state: "This database is made available under the Open Database License" (ODbL 1.0); they also contain a CC0 1.0 licence file. Not redistributed. |
| Iowa Environmental Mesonet (IEM), Iowa State University, ASOS/METAR archive | Weather features | IEM states that its materials are in the public domain and that attribution to the Iowa Environmental Mesonet of Iowa State University is appreciated. Not redistributed. |
| X-Plane Scenery Gateway (`apt.dat` airport data) | Stand and runway positions (merged with OpenStreetMap); taxiway network for the stand-to-runway path lengths of the tabular features | We found no licence statement for Gateway airport data on https://gateway.x-plane.com/, https://developer.x-plane.com/?p=5583 ("About the Airport Scenery Gateway") or https://developer.x-plane.com/?p=6508 (data development documentation), nor in the scenery packs we downloaded. We therefore redistribute no Gateway data and nothing derived from it: this repository contains only the download script `pipeline/data/fetch_xplane_apt.sh` and the merge script `pipeline/data/stand_merge.py`, and users obtain `apt.dat` from the Gateway themselves. Not redistributed. |
| EUROCONTROL "Taxi-Out Additional Time" monthly data | Evaluated only (appendix B); not used for predictions | The ansperformance.eu disclaimer states that the data may be copied in whole or in part provided that EUROCONTROL is mentioned as the source and that it is not used for commercial purposes. Source: EUROCONTROL. Not redistributed. |
